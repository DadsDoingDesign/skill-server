Embed a skill

Generate a live, embeddable widget for any skill on this server — name + description with working Copy, Open, and MCP buttons. Drop the snippet into a Grids embed tile or any page. The widget reads from this server's /api/skills, so it stays in sync automatically.

The widget reflows between card / compact / row as you resize the tile, and it's transparent so your tile background shows through — choose Dark for a dark grid (and optionally an accent to match). allow="clipboard-write" lets the Copy/MCP buttons work cross-origin. Embedding from a different domain than this server needs CORS on /api/skills; hosting the widget on this server (the default) avoids that.

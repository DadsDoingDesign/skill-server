Skill Embed Widget

Ten concepts for a Grids tile that embeds one skill from the skill-server. Every concept carries the same four parts — name + description, a Copy button (full SKILL.md text), an Open link to the skill page, and an MCP button (copies the claude mcp add command). Built on the skill-server paper/ink tokens. Click any button — they work.
